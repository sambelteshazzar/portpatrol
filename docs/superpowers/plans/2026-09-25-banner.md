# Terminal Banner Implementation Plan

> **For agentic workers:** Implement one task at a time, in order, with TDD (write the failing test, watch it fail, implement, watch it pass, commit). Steps use checkbox (`- [ ]`) syntax for tracking. Run tests from the repo root: `python3 -m pytest tests/ -v`.

**Goal:** bare `portpatrol` prints an ASCII wordmark of the tool name on stderr above the default scan.

**Architecture:** a new `portpatrol/banner.py` holds the pre-rendered `BANNER` constant and a best-effort `print_banner(stream)` helper; `main()` calls it only when no subcommand was given. stdout and all explicit subcommands stay byte-identical to today.

**Tech Stack:** Python 3.8+ stdlib only. The art was rendered once with pyfiglet (figlet `standard` font) in a throwaway environment and is baked into the source as a string.

**Spec:** `docs/superpowers/specs/2026-09-25-banner-design.md`.

## Global Constraints

- The banner goes to stderr only, and only when `args.command is None`.
- stdout of every command stays byte-identical to the current behavior.
- The art is pure ASCII with no ANSI escape codes, ever.
- Python 3.8+ stdlib only; no new runtime dependency.
- Exit codes unchanged; the current suite stays green.
- Art: figlet `standard` spelling `PortPatrol`, 5 rows, widest row 48 columns, trailing whitespace stripped (exact rows are in the spec's Art section).

    assert all(row for row in rows), "banner must have no empty rows"

- [ ] **Step 3: Implement `portpatrol/banner.py`**

```python
"""ASCII wordmark printed on bare invocation."""

from __future__ import annotations

BANNER = "\n".join((
    " ____            _   ____       _             _",
    "|  _ \\ ___  _ __| |_|  _ \\ __ _| |_ _ __ ___ | |",
    "| |_) / _ \\| '__| __| |_) / _` | __| '__/ _ \\| |",
    "|  __/ (_) | |  | |_|  __/ (_| | |_| | | (_) | |",
    "|_|   \\___/|_|   \\__|_|   \\__,_|\\__|_|  \\___/|_|",
))


def print_banner(stream):
    """Write the wordmark and a blank line to stream, best-effort."""
    try:
        stream.write(BANNER + "\n\n")
    except OSError:
        pass
```
